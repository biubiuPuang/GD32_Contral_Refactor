# 无线底层驱动模拟验证

在 Windows 安装 Python 3 和 Visual Studio C++ 编译工具后，于仓库根目录执行：

```text
python tests/wireless/run.py
```

测试将两端实际的 C 驱动分别编译为主机程序。模拟 GPIO 模型检查时钟先开启、仅访问四根线、CSB/FCSB 互斥、SDIO 输入输出方向、SPI 字节顺序及 FIFO 事务；模拟芯片状态检查中断极性、轮询不清标志、超时退出和未连接芯片的失败返回。

不读取或控制实际开发板，也不能代替实物电气时序、RFPDK 配置和无线收发验证。编译产物放在本测试目录下的临时文件夹，运行结束自动清理。

# F50：50个可选频道候选实现

当前实现每套固定一个频道，配置时使用AN197官方手动跳频机制。不是运行时同步跳频或时分组网。支持50套分别选择不同的名义频点，不代表已经证明50套在工业现场同时可靠工作。

## 使用方法

1. 发送端与接收端同时升级对应F50固件；启动行应含V4 F50。
2. 两端串口使用115200、8N1、ASCII，命令末尾发送换行。
3. 同一套的两端输入相同SET命令；不同套分配不同ID及CH。ID仍支持1～4294967295，ID=0无效，CH只能为0～49。
4. 等待OK SAVED APPLIED，再发送GET核对两端ID/CH/FREQ相同，PAIRED=1、SAVE=OK、RADIO=OK。

第1套：两端分别输入 `SET,1,0`；第50套：两端分别输入 `SET,50,49`。原有GET、HELP、DEFAULT含义保持，DEFAULT仍取消配对。普通断电保留ID/CH；整片擦除仍会清除配置。

旧六频道固件的ID/CH记录格式没有更改，F50仍可加载原数值，但对应频率已改变。两端必须升级相同频率方案并重新核对GET，不能将旧六频道端与F50端混用。

## 初始化和资料依据

- 现有BSP继续负责GPIO/SPI/USART/TIMER时钟与初始化，无新增外设。频率区和频道设置都在现有初始化的STBY阶段通过官方BSP写入并读回验证，随后按原流程进入TX/RX。
- 原始.exp和96字节数组保留；应用层wireless_frequency_plan.h只替换0x18～0x1F频率区：`42 78 D9 1A 42 62 27 1A`。26MHz晶振、DIVIDER=4，RX LO比RF高26MHz/92，TX LO等于RF；保留原PALDO、DIVX、VCO_BANK和FSK_SWT配置。
- AN197：频率=基础频点+约2.5kHz×FH_OFFSET×FH_CHANNEL。基础频点改为433.125MHz，步进参数13，频道号0～49。
- AN1971：按项目设计假设TX/RX各40ppm、26MHz、DIVIDER=4重算，全部50频点的AFC_OVF_TH均为21；接收端写入0x27并读回验证。40ppm是设计输入，未在本次测量实物。
- [AN199官方频率字计算说明](https://www.hoperf.com/uploads/AN199-CMT2300A-CMT2119B-CMT2219B_RF_Frequency_Calculation_Guide_EN_1695688705.pdf)补充用于基础频点寄存器计算；独立计算可还原原433.920MHz导出值。

## 本机验证

在工程根目录运行：

```powershell
python 211_Project/wu-xian-App/validation/check_fifty.py
```

脚本复用现有MinGW行为测试与原始Keil工程，检查全部50频道的设置、持久化、边界拒绝、ID过滤、85ms超时、完整控制回归；独立核算频率字并核对原始AN1971公式。对142份非本次修改范围文件做SHA256检查，并比较原控制/收发/计时等函数。输出fifty_summary.json及原构建目录下的HEX，不访问串口、不烧录。

## 验证边界

本次交付的是50个可选固定频道的候选版本。32.5kHz间隔下的邻频隔离、50套真实并发、通信距离和载人用途安全均未完成实测。单套逐频点通信测试通过也不能作为50套并发通过。当前发射功率、GFSK速率/频偏和接收带宽沿用原参数，因此这些射频限制没有因频道数量变化而消失。85ms仍仅是无线命令有效期，原有有线参与、无线急停超时行为未更改。
